Chapter 11 — Isometric Transformations

11.2 Translation
← Back to Mathematics Hub

Translation = Same Direction + Same Distance

Object and image keep the same shape, size and orientation.

Translation Vector

(a / b)

a: right (+), left (−)
b: up (+), down (−)

Coordinate Rule

Object → Image:

P(x,y) → P′(x+a,y+b)

Image → Object:

P(x′−a,y′−b)

Quick Check

A(2,3) translated by (4 / 2). Find A′.
